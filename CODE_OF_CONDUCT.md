# Code of Conduct

Critique claims, evidence, definitions, and proofs—not people. Be precise, civil, and willing to revise conclusions when evidence changes.

Harassment, threats, discrimination, doxxing, fabricated evidence, attribution attacks without evidence, and deliberate misrepresentation are unacceptable.

Maintain the distinction between discovering an error and alleging misconduct. Report private security or sensitive-data concerns through `SECURITY.md` rather than publishing them prematurely.

# Governance

## Principles

1. Evidence outranks authority.
2. Reproducibility outranks rhetoric.
3. Failed tests remain visible.
4. Criteria are versioned before execution.
5. Unknown findings remain unknown.
6. Mathematical and institutional verdicts remain separate.

Material changes to theorem scope, scoring, verdict thresholds, or evidence handling require a dated decision record describing the change, motivation, alternatives, and effect on prior results.

Completed run directories are immutable. Corrections create a new run and delta report. Reviewers disclose relevant affiliations and prior participation.
